# Internal Pilot Corpora

**Status:** DRAFT. Not real production traffic. SCRIPTED_TECHNICAL_PROOF only.

Each file is a JSONL of `policy_core_v3_corpus.CorpusDialog` records. Each
dialog has a `status` field:

- `draft` — generated by the agent; **not** owner-approved. Useful for
  pipeline mechanics testing.
- `owner_approved` — reviewed and approved by the owner; counts as
  `INTERNAL_PILOT_PROOF` for that dialog.
- `deprecated` — kept for history; do not use in cutover gate.

A corpus aggregate report cannot count as `INTERNAL_PILOT_PROOF` until
`owner_approved` covers ≥30 dialogs across the coverage matrix
(see `SPECS/SHADOW_RUN_V3.md` Phase B.3 acceptance).

## Format

```jsonl
{"dialog_id": "...", "locale": "ru-KZ", "status": "draft", "notes": "...",
 "turns": [
   {"turn_index": 0, "current_message": "...", "history": [...],
    "state_slots": {...}, "evidence_bundle": [...],
    "legacy_summary": {...}, "oracle_v3": {...}}
 ]}
```

`legacy_summary` is the agent's hypothesis of what the legacy
`intent_service` would emit for this turn; `oracle_v3` is the agent's
hypothesis of what v3 SHOULD emit. Both are draft until owner audit.
