# Inbox UX v2 + macros (DB-backed)

**Date:** 2026-01-30
**Scope:** Inbox (Cases) UI + Console API for быстрые ответы (персональные/командные).

## Что изменили
- Chat-first layout: чат — основной, детали открываются по кнопке и скрыты по умолчанию.
- RU-копия по Inbox/Details, разделение «операторских» данных и диагностики.
- Быстрые ответы переведены на макросы в БД (per client/branch/agent), с управлением в UI.

## UX-итоги
- Очередь → Чат → Детали: понятный путь, без «тех» шума в основном потоке.
- Контекст закреплён над чатом («Суть запроса» + last inbound).
- Диагностика доступна отдельной вкладкой только для support/admin ролей.

## Тех. заметки
- Новая сущность `console_macros` + CRUD в `/console/v1/inbox/macros`.
- Макросы разделяются на personal/team; RBAC на edit других агентов.
- Консоль использует API-типизацию из OpenAPI.
