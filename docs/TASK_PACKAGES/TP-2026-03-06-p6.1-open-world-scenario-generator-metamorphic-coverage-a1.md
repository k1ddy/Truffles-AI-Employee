## Root cause (mandatory)

- Symptom:
  - the current open-world generator mostly emits Russian phrasing and contains only one hard-coded RU/KZ mixed template, so the new invariant gates still do not get deterministic multilingual/code-switch pressure.

- Minimal reproduction:
  1. inspect `SCENARIOS`, `INTERRUPTIONS`, `EXTRA_TURNS`, and `FALLBACK_TEMPLATES_BY_TAG` in `scripts/booking_dialog_scenarios.py`
  2. `rg -n "booking_kz_mix|language_profile|code_switch|translit|metamorph" scripts/booking_dialog_scenarios.py truffles-api/tests/test_booking_dialog_scenarios_script.py`
  3. observe there is no parameterized language profile or deterministic mutation family in the script/tests

- Evidence:
  - `scripts/booking_dialog_scenarios.py`
    - one explicit `booking_kz_mix` template exists, but the rest of the scenario surface is Russian-first
    - no CLI/config surface for multilingual or code-switch generation
  - `truffles-api/tests/test_booking_dialog_scenarios_script.py`
    - tests cover tag/expect mechanics and LLM error handling, but not multilingual/code-switch mutation coverage
  - `docs/TASK_PACKAGES/TP-2026-02-19-llm-first-firebreak-program.md`
    - mandatory multilingual adversarial battery explicitly requires `RU`, `KK`, and mixed `RU+KK`

- Five Whys:
  1. Why is multilingual proof still missing: the generator does not systematically emit multilingual variants.
  2. Why is that a problem: acceptance evidence remains biased toward one surface language and can miss regressions on mixed phrasing.
  3. Why do current tests not catch it: tag/expect contracts are checked only on the existing Russian-biased templates.
  4. Why is the generator the right place to fix it: this is a quality-evidence gap, not a runtime-core semantic ownership gap.
  5. Why is the next block small: adding a deterministic mutator gives new coverage without burning more LLM budget.

- Root cause statement:
  - open-world validation lacks a reusable, seed-stable mechanism to project the same scenario semantics into multiple language surfaces.

- Fix mechanism:
  - add `language_profile=ru|kk|mixed` to the deterministic scenario generator
  - apply tag-aware, seed-stable surface mutation after template formatting while preserving tags and expectations
  - add deterministic tests that prove the same contract survives under `kk` and `mixed` variants
