## Root cause (mandatory)

- Symptom:
  - After the LLM plan is parsed, deterministic code still reconstructs semantic inputs from user text and local classifiers.
  - This preserves a second semantic owner even after P1.4 removed tool-hint lexical routing.

- Minimal reproduction:
  1. `rg -n "policy_pack_refs = _derive_policy_info_refs|aligned_to_turn_hint" truffles-api/app/routers/webhook/decision.py`
  2. `sed -n '9995,10105p' truffles-api/app/routers/webhook/decision.py`
  3. `sed -n '12705,12770p' truffles-api/app/routers/webhook/decision.py`

- Evidence:
  - `truffles-api/app/routers/webhook/decision.py`
    - `info` plan without refs can still recover refs from `info_class_intents`, `_has_lateness_signal`, `_derive_policy_info_refs`, and slot text.
    - `catalog.service_query` can still replace `service_query` with `_extract_service_hint(message_text, ...)`.
  - `truffles-api/tests/test_message_endpoint.py`
    - Existing contract test still encoded `turn_service_hint` alignment as expected runtime behavior.

- Five Whys:
  1. Why does semantic override persist: validator still tries to "help" incomplete plans.
  2. Why is this dangerous: semantic gaps are hidden instead of surfaced as contract violations.
  3. Why does it break LLM-first: user text becomes a second source of semantic truth after the owner decision.
  4. Why does it not scale: rescue depends on language/lexicon and niche-specific phrasing.
  5. Why fix now: replay/realism after this point would measure a mixed-owner runtime, not the target architecture.

- Root cause statement:
  - Post-plan validation still contains text-driven semantic recovery, so the deterministic layer continues to reconstruct meaning after the LLM owner has already spoken.

- Fix mechanism:
  - Remove post-plan recovery of `pack_refs` and `service_query` from `message_text` and classifier outputs.
  - Keep only plan-owned inputs (`tool_args`, plan refs) and fail closed on missing semantic refs.

## Invariant

2. `service_query` is not rewritten from turn text after the plan.
