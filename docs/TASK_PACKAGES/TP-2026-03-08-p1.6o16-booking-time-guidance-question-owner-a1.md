## Interaction taxonomy (binding)

- `fill_requested_slot`: user directly provides the missing slot value.
- `ask_about_requested_slot`: user asks for advice, clarification, or guidance about the currently requested slot before filling it.
- `slot_constraint`: user narrows the requested slot (`утром`, `после обеда`, `не позже шести`) without fully filling it.
- `slot_compare`: user compares slot options (`утром или вечером`, `сегодня или завтра`) relative to the active requested slot.
- `mixed_fill_plus_question`: user partially answers the slot and adds a side-question or comparison in the same turn.
